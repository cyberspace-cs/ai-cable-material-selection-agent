# 交付说明：逐条对照 A 题要求

> 面向评审：本题要求「运行原型 + 代码/数据 + 10 分钟讲解」。本文按题面顺序说明每一条要求落在哪个文件、怎么验证、以及哪里还没做到。

---

## 0. 一句话定位

**不是让模型写一段选型建议，而是把选型拆成可验证的三步：规则做合规过滤 → 打分做同层排序 → 证据做结论绑定。大模型只负责把结构化结果复述成人话，且可以完全不用。**

这条路线直接对应题面「不能只展示一段无依据的自由生成文本」。

## 2. 交付物（题面第四节）

### 2.1 可运行原型

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8000     # → http://127.0.0.1:8000
```

- **无需任何密钥**：未配置 `LLM_API_KEY` 时，叙述层走 `offline-template`，七层结果、得分、风险、引用全部照常。
- **跑通案例**：4 个预设场景（S1–S4）+ CLI 任意输入，超过题面要求的 3 个。
- **演示入口**：`screenshots/` 下 6 张（Web 4 张 + CLI 2 张），README 首屏内嵌。
- **CLI**：`python -m app.cli --scenario S2`，与 Web 共用同一引擎，用于脚本化验证。

### 2.2 代码与 README

`README.md` 覆盖题面点名的五项：安装/启动、技术架构、模型与数据依赖、已知限制、成本或密钥。

关键取舍写在 README 的「为什么不用向量 RAG」一节：**选型是约束满足问题，不是相似度问题**。单芯交流回路禁用钢带铠装是硬规则，不能被「这段文本很像」覆盖掉。

### 2.3 材料数据集

结构化 JSON，字段说明写在 `meta.schema`，四级证据定义写在 `meta.evidence_levels`，**已知缺陷写在 `meta.known_gaps`**：

- `attrs` 里的 0–3 是工程序数分，只能同层比较，不能跨层；
- 阻燃 A/B/C/D 是成品级结论，材料记录只有氧指数，不能推成品等级；
- 未收录具体牌号 TDS，同类别内耐寒/耐油差异可能很大 —— 这条直接导致了 T-05 失败。

每条记录都有 `sources`（指向 `standards.json` 的 id）与 `updated_at`，运行时校验引用完整性，测试 `test_engine.py` 会拦截悬空引用。

### 2.4 设计说明

`docs/DESIGN.md`：为什么规则优先、打分怎么设计、权重为什么随场景变、幻觉怎么压、5 天改进优先级。

### 2.5 验证记录

`docs/VALIDATION.md` + `data/validation.json`：**5 条**，每条含输入、预期、实际、判定、说明。

其中 **T-05 是真实失败案例**（-40℃ 户外直埋仍推荐常规 LSZH 护套，且置信度 0.77 偏高）。根因不是规则写错，而是材料颗粒度只到类别不到牌号，导致「唯一没被排除的候选」被当成「推荐」。改进方向：护套按牌号细分 + 候选集 ≤1 时拒答。

## 3. 两个基准场景的实际输出

| | S1 基准（题面给定） | S2 开放（沿海/防鼠/耐紫外） |
|---|---|---|
| 输入 | `YJV-0.6/1kV 4×35+1×16`，桥架，40℃，成束，阻燃+低烟 | `WDZ-YJY-0.6/1kV 3×120+1×70`，户外沿海，45℃，ZB，B1，盐雾+鼠害+UV |
| 关键判断 | 识别 **YJV 的 PVC 护套与低烟要求冲突**，给出 `WDZ-YJY` 而非静默替换 | **铠装从钢带切到铝合金连锁**：耐蚀权重 0.04→0.26，压过成本 |

S1 的「型号冲突」是刻意设计：**输入型号与需求矛盾时先暴露矛盾，再给方案**，而不是悄悄换成另一个型号让结果好看。

## 5. 评审四问的直接回答

**Q1 从哪些资料学？如何判断可信、如何处理矛盾？**

起点是 `GB/T 12706`（挤包绝缘电力电缆）、`GB/T 3956`（导体）、`GB 50217`（敷设设计）、`GB/T 19666`（阻燃耐火）、`GB 31247`（燃烧性能分级）、`GB/T 32129`（无卤低烟料），辅以《电线电缆手册》。可信度排序：**强制性国标 > 推荐性国标/行标 > 厂商 TDS > 教材 > 网络文章**。

三类矛盾的处理：

1. **型号与需求矛盾**（YJV 却要低烟）→ 不静默替换，出 `warn` 并给升级型号；
2. **标准版本冲突**（GB/T 12706 2008 vs 2020）→ 统一取 2020，旧版参数不进入库；
3. **口径不一致**（氧指数、卤含量各家测法不同）→ 只用于材料级筛选，**明确拒绝**用它推成品阻燃等级或 GB 31247 分级。

**Q2 为什么选这条路？模型挂了怎么办？**

选型的第一性问题是「哪些组合合规」，这是约束满足，不是语义相似。纯 RAG 的风险是：检索到的条款可能属于另一个电压等级或另一种结构，模型会把不适用条款拼进结论，而且错得很像对的。所以判断层用确定性代码，检索/生成只放在解释层。

模型不可用：`llm.py` 捕获无 key、超时、返回异常，回退 `offline-template`，返回体 `narrative.mode=fallback`。**核心结论不依赖模型**，这是刻意设计，不是兜底。

**Q3 什么输入会追问、要求复核、拒答？**

- **追问**：成束根数、腐蚀介质类型与浓度、是否变频器负载、消防等级 —— 这些直接改变结论，缺失时进 `questions`；
- **要求复核**：阻燃 A/B/C/D 类、GB 31247 分级、载流量修正、短路热稳定 —— 属成品级或系统级结论，`checks` 里标 `warn` 并写明「不能作为合规声明」；
- **拒答**：目前只在候选集为空时报错，**没有做到「候选集=1 就拒答」**，T-05 就是因此失败。这是已知缺口，不是没想到。

**Q4 再给 5 天，补数据、算法还是验证？**

**补数据。** T-05 的根因是护套只到「LSZH 类别」不到「-40℃ 耐寒牌号」，此时再好的算法也只能在错的候选集里排序。优先级：① 护套/绝缘按牌号补 TDS（耐寒、耐油、耐紫外）；② 引入「候选集不足即拒答」的置信度门槛；③ 用真实项目选型单回流做验证集。算法层暂时不需要动。

## 6. 明确的边界声明

- 结论是**材料级选型建议**，不等于成品合规；阻燃等级与 GB 31247 分级必须整体送检。
- `attrs` 的 0–3 分是工程序数，用于同层排序，**不可跨层比较，也不是物理量**。
- 覆盖范围：0.6/1kV 与 8.7/15kV、26/35kV 挤包绝缘电力电缆；不含矿用、船用、核电等特种电缆。
- 未做：载流量计算、短路热稳定校验、电缆结构尺寸计算、报价。
