# 设计说明

> 目标读者：评审。回答三个问题——为什么这样选技术路线、如何降低幻觉、边界在哪里。

## 1. 问题拆解

材料选型的本质不是"生成一段文本"，而是**在约束下做多目标决策，并对每个决策负责**。拆成四个可验证的子问题：

| 子问题 | 失败模式 | 本项目的处理 |
|---|---|---|
| 型号 → 结构是否合法 | 把 26/35kV 单芯套用 YJV22 的钢带铠装 | 型号解析 + 硬约束，直接排除并报 error |
| 材料是否满足工况 | 低烟场景推荐 PVC，-40℃ 推荐常规 LSZH | 需求推导 + 硬过滤 + 低温警告 |
| 层与层是否自洽 | 无卤护套配 PP 填充 | 层间耦合检查，跨层规则统一裁决 |
| 结论是否有据 | LLM 编造条款号 | 证据从材料库固定绑定，模型无权新增事实 |

## 2. 为什么是"规则 + 打分 + 证据绑定"，不是纯 RAG / 纯 LLM

**结论：在 29 条材料的封闭集合上，纯向量 RAG 是负收益。**

理由有三：

1. **召回不可控**。向量检索最容易犯的错是把中压条款召回到低压场景——两者文本相似度极高，但适用性完全不同。这类错误在工程上比"没有答案"更危险。
2. **证据需要确定性**。合规结论要求"这条推荐 → 这条标准"是固定映射，不能随 embedding 相似度漂移。
3. **可解释性要求排序依据**。评审会问"为什么是铜不是铝"，向量相似度回答不了；加权准则可以逐项摊开（见结果页的"理由"行）。

因此采用三层结构：

```
硬约束（合规/安全，布尔）  →  加权打分（工程偏好，0-100）  →  证据绑定（引用，固定）
```

**硬约束永远优先于打分**。T-04 是这条原则的验证：钢带铠装得分更高，但单芯交流回路直接排除，改推荐铝合金连锁。

### 打分为什么用序数而不是物理量

层内候选的差异很多是定性的（耐蚀、柔性、工艺性），硬套物理量会制造虚假精度。做法是把每项归一化到 0–1，权重随需求动态调整，最后映射到 0–100：

| 场景 | 关键权重变化 |
|---|---|
| 常规低压 | 成本 0.28，阻燃 0.18 |
| 低烟无卤 | 阻燃+低烟 0.26，成本降至 0.20 |
| 沿海腐蚀 | 导体耐蚀 0.16，铠装耐蚀 0.26（默认 0.04） |
| 低温 | 护套低温项 0.14（默认 0.04） |

权重是显式常量，写在 `engine.py` 的各 `_score_*` 函数里，可被评审直接质疑和替换——这比藏在模型参数里更诚实。

### 置信度怎么算

```
0.90 − 0.12×error − 0.045×warn − 0.05×(成束根数缺失) − 0.04×(未指定 B1/B2) − 0.03×(中压)
```

不是概率，是**信息完备度的代理指标**。所以它只在 0.30–0.95 之间，且从不宣称"确定"。

## 3. 如何降低幻觉

四道闸门，任何一道都不依赖模型自觉：

1. **事实不出库**：材料名、牌号、性能值、标准号全部来自 JSON，模型输入是裁剪后的结构化事实（`llm.py::_facts`），输出被要求为 JSON schema。
2. **证据分级**：`standard / document / engineering / assumption` 四级，在 UI 上以不同颜色 chip 呈现。工程经验不会被写成"标准规定"。
3. **引用精确度自曝**：绝大多数引用是 `precision: standard`（标准 + 要求项），**没有条款号就是没有**，不编造页码。
4. **降级可见**：无 Key 走模板；LLM 异常走 fallback，`narrative.mode` 会写 `offline-template (fallback)`，失败原因一并返回。

此外，**拒答与追问是一等公民**：
- 成束根数未知 → 降低置信度 + 明确追问，而不是猜一个阻燃等级；
- B1 级 → 明确声明"材料指标不能推定成品分级"；
- 中压 → 追问中性点接地方式与单相接地持续时间。

## 4. 一个被保留的失败

T-05（-40℃ 户外直埋）没有通过：引擎仍推荐常规 LSZH 护套，只给了一条 warning。

根因不是规则写错，而是**数据粒度不够**：材料库每个类别只有一条 LSZH 记录，没有"耐寒牌号"这一层，导致"唯一未被排除的候选"被当成"推荐"。这暴露了一个更普遍的问题——**打分系统在候选集退化时不会自动拒答**。

改进方向（未在本版实现，因为需要真实牌号 TDS）：
1. 护套按牌号细分，增加 `low_temp_limit` 字段；
2. 当最高分候选触碰硬边界（如低温下限）时，返回 `insufficient_evidence` 而不是强行排序；
3. 增加"候选集退化"检测：若某层可用候选 ≤1，置信度强制上限 0.6。

## 5. 如果再有 5 天

优先级：**补验证 > 补数据 > 补算法**。

- 补验证（2 天）：找 3~5 位一线工艺/设计工程师盲评 10 组输出，统计"可接受/不可接受"，比再多的规则都更能说明问题。
- 补数据（2 天）：护套与绝缘细分到牌号，补 `low_temp_limit`、`oil_resistance_grade`、`uv_rating` 三个字段，直接修掉 T-05。
- 补算法（1 天）：接入 GB 50217 载流量表，把"截面是否够"从假设变成计算。

算法排在最后，因为当前瓶颈不在算法，而在**证据粒度**。
